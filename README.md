# SwiftCart Order Management System

## Overview
SwiftCart is a frontend-based ecommerce Order-to-Delivery workflow simulation project developed as part of an internship assignment.

The project demonstrates:
- Order Validation
- Inventory Checking
- Payment Processing
- Tracking Simulation
- Delivery Workflow

---

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Draw.io

---

## Features
- Modern Glassmorphism UI
- Animated Gradient Background
- Inventory Validation
- Tracking ID Generation
- Delivery Tracking Simulation
- Notification Popups
- Responsive Design
